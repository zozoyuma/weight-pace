Weight Pace Web App

1. index.html / app.css / app.js / manifest.webmanifest を同じフォルダのままWebサーバーへ配置してください。
2. iPhoneのSafariで公開URLを開けば利用できます。
3. Safariの「共有」からホーム画面へ追加すると、アプリ風に起動できます。

重要:
- ZIPをiPhoneで開くだけではホーム画面アプリにはできません。Webサーバー上のURLが必要です。
- 記録はブラウザのlocalStorageに保存されます。Safariのサイトデータ削除で消えるためCSVバックアップ機能を用意しています。
- 消費カロリーはMETsによる概算で、医療用途の値ではありません。
